# NakuruHub (Next.js)

Next.js App Router port of the NakuruHub static prototype (`C:\Users\mhki\nakuruhub\nakuruhub`). Marketing and demo UI use the original Flamingo Lake CSS (`app/nakuru-globals.css`), not a Tailwind rewrite.

## Requirements

- [pnpm](https://pnpm.io/) 9+ (see `packageManager` in `package.json`)

## Scripts

| Command | Purpose |
|---------|---------|
| `pnpm dev` | Dev server at [http://localhost:3000](http://localhost:3000) |
| `pnpm build` | Production build |
| `pnpm start` | Run production server (after `build`) |
| `pnpm test` | Vitest (`lib/nakuru/format.test.ts`, etc.) |
| `pnpm lint` | ESLint |
| `pnpm seed:demo` | Insert demo vendors/listings into Postgres (safe upsert; see below) |
| `pnpm vendors:promote` | Verify a live vendor and pin their shop on the home hero |

## Routes

| URL | Page |
|-----|------|
| `/` | Marketing landing (EN/SW) |
| `/app` | Interactive marketplace demo |
| `/app?start=vendor` | Opens vendor signup in the demo |

Legacy paths redirect via `next.config.ts`: `/landing.html` → `/`, `/index.html` → `/app`.

## Fonts & PWA

- Self-hosted **Bricolage Grotesque** and **Figtree** in `public/fonts/` (loaded via `@font-face` in CSS; preloaded in root `layout.tsx`).
- Web app manifest: `public/manifest.webmanifest`. Wordmark lockup: `lib/nakuru/logo-lockup-source.jpg`; square app icon: `lib/nakuru/pwa-icon-source.jpg`; favicons, PWA icons, `app/icon.png`, and Open Graph image via `pnpm icons:pwa`.
- **PWA / install:** Service worker `public/sw.js` registers on `/app`. Install UI is in the marketplace shell only. Service workers and “Add to Home screen” work on **HTTPS** or **http://localhost** only — not on `file://`.
- **Local PWA test:** `pnpm build && pnpm start` (or `npx serve out` if exporting static), open `/app` in Chrome, use DevTools → Application → Manifest / Service workers. For a quick static server: `npx serve public -p 3000` does **not** run the Next app; use `pnpm dev` or `pnpm start` instead.

For production canonical URLs, set `NEXT_PUBLIC_SITE_URL` (e.g. `https://nakuruhub.co.ke`) so Open Graph and sitemap metadata resolve correctly. It defaults to `https://nakuruhub.co.ke`. Set `GOOGLE_SITE_VERIFICATION` to the Search Console HTML-tag token to emit the verification meta tag.

## Demo catalog (screenshots)

The built-in demo listings in `lib/nakuru/data/items.ts` use specific Nakuru titles, descriptions, and photos, with a mix of verified (`v: 1`) and unverified (`v: 0`) sellers. They appear when live catalog is off (default): leave `NEXT_PUBLIC_USE_LIVE_CATALOG` unset or `false`, then restart `pnpm dev` and open `/app`.

For Postgres-backed demos, run **`pnpm seed:demo`** (requires `DATABASE_URL` in `.env.local`). It upserts a smaller, photo-led set (denim jacket, charger, sukuma pack, plumber, rentals, plots, Axio) owned by `demo-seed-*@seed.nakuruhub.local`. Stale demo listings without a current `seedKey` are removed; real vendors are never touched. See `docs/IMAGES.md`.

To verify the first live shop and pin it on the hero (default email `tracywairimu43@gmail.com`):

```bash
pnpm vendors:promote
```

The script **never deletes** customer or vendor data you created outside the demo. To wipe and re-insert **only those demo rows**, run:

```bash
pnpm seed:demo -- --reset
```

You can also add products through the vendor flow or SQL in the Supabase dashboard; avoid manual deletes in a shared database.

## QA (local)

Playwright specs live under `e2e/` (ported from the prototype’s visual QA). With the dev server running:

```bash
pnpm exec playwright test e2e/landing.spec.mjs
pnpm exec playwright test e2e/app-smoke.spec.mjs
```

## Deploy

Standard Next.js deploy (e.g. [Vercel](https://vercel.com/docs/frameworks/nextjs)): `pnpm build`, set `NEXT_PUBLIC_SITE_URL`. `robots.txt` and `sitemap.xml` are generated by `app/robots.ts` and `app/sitemap.ts`.
